Коротко о процессе

Мы приводим таблицу к единому формату, подключаем AppSheet, настраиваем автоматизации и визуальную часть. Следуйте пунктам — ничего не нужно придумывать или доделывать.

Роли

Менеджеры работают только со своими строками, а администратор видит всю смету и получает еженедельный отчёт.

Этап 2

Настройка данных в AppSheet (Data)

Регистрируем новые колонки и задаём типы с формулами.

  1. В редакторе AppSheet откройте Data → Смета.
  2. Нажмите Regenerate Structure.
  3. Настройте каждую колонку по таблице ниже.
Колонка Тип Настройки
ID Text Initial Value: UNIQUEID(), Key: ✅, Show?: ❌
Статья Enum Valid If: Справочник[Статья]
Тип платежа Enum Добавьте значения: Аванс, Постоплата, Погашение кредиторской задолженности.
Контрагент Enum Suggested Values: Справочник[Контрагент], при необходимости Allow other values.
КЗ / КЗ_Крит Number Decimal digits: 0, Thousands Separator: On, описание «в тыс. руб.»
Week_0 Number Display Name: "Н" & WEEKNUM(TODAY()) & " (" & TEXT(TODAY(), "dd.mm") & ")"
Week_1…Week_9 Number Та же формула, но с TODAY()+7, +14 … +63.
Статус Enum Значения: Черновик, Отправлено, Утверждено. Initial Value: Черновик.
Менеджер Email Initial Value: USEREMAIL(), Editable?: ❌

Editable_If для сумм и контрагента

AND([Статус] <> "Утверждено", [Статус] <> "Отправлено")

Менеджер редактирует только в статусе «Черновик».

Этап 3

Безопасность (Security) — критично

Менеджеры должны видеть только свои строки.

  1. Перейдите в Security → Security Filters.
  2. Выберите таблицу Смета.
  3. Вставьте фильтр ниже, заменив email администратора.
OR(
  USEREMAIL() = "ВАШ_EMAIL_АДМИНА@gmail.com",
  [Менеджер] = USEREMAIL()
)
Этап 4

Скрипт автоматизации (мозг системы)

По понедельникам: отправка Excel, архив и сдвиг недель.

  1. В Google Таблице откройте Расширения → Apps Script.
  2. Удалите код и вставьте скрипт ниже.
  3. Замените ВАШ_EMAIL@gmail.com на ваш.
function mondayNightProcessing() {
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var sheet = ss.getSheetByName("Смета");
  var archiveSheet = ss.getSheetByName("Архив_Факта");

  // 1. Отправка отчета (XLSX) на почту
  var emailTo = "ВАШ_EMAIL@gmail.com";
  var url = "https://docs.google.com/spreadsheets/d/" + ss.getId() + "/export?format=xlsx&gid=" + sheet.getSheetId();
  var params = {
    method: "GET",
    headers: { "Authorization": "Bearer " + ScriptApp.getOAuthToken() },
    muteHttpExceptions: true
  };
  var blob = UrlFetchApp.fetch(url, params)
    .getBlob()
    .setName("Смета_" + Utilities.formatDate(new Date(), Session.getScriptTimeZone(), "yyyy-MM-dd") + ".xlsx");

  try {
    MailApp.sendEmail({
      to: emailTo,
      subject: "Смета (Понедельник)",
      body: "Файл во вложении.",
      attachments: [blob]
    });
  } catch (e) {
    Logger.log("Ошибка почты: " + e);
  }

  // 2. Архивация и сдвиг
  var lastRow = sheet.getLastRow();
  if (lastRow < 2) return;

  var data = sheet.getRange(2, 1, lastRow - 1, 18).getValues();
  var archiveData = [];
  var today = new Date();

  for (var i = 0; i < data.length; i++) {
    var row = data[i];
    var sumWeek0 = row[6];
    if (sumWeek0 && sumWeek0 != 0) {
      archiveData.push([today, row[1], row[2], row[3], row[17], sumWeek0]);
    }
  }

  if (archiveData.length > 0) {
    archiveSheet.getRange(archiveSheet.getLastRow() + 1, 1, archiveData.length, 6)
      .setValues(archiveData);
  }

  // 3. Сдвиг недель (Week 1 -> Week 0)
  var rangeToMove = sheet.getRange(2, 8, lastRow - 1, 9);
  var valuesToMove = rangeToMove.getValues();
  sheet.getRange(2, 7, lastRow - 1, 9).setValues(valuesToMove);
  sheet.getRange(2, 16, lastRow - 1, 1).setValue(0);
}

Триггер

Функция mondayNightProcessing → по времени → еженедельно → понедельник → 00:00–01:00.

Этап 5

Действие «Умное копирование» (Actions)

Копирование строки без контрагента, чтобы менеджер выбирал заново.

  1. AppSheet → Actions → New Action.
  2. Name: Копировать строку.
  3. Table: Смета.
  4. Do this: App: go to another view within this app.
LINKTOFORM("Смета_Form",
  "Статья", [Статья],
  "Тип платежа", [Тип платежа],
  "Week_0", [Week_0],
  "Week_1", [Week_1],
  "Week_2", [Week_2],
  "Week_3", [Week_3],
  "Менеджер", USEREMAIL()
)

Контрагент не указывается → поле будет пустым и обязательным для выбора.

Этап 6

Визуализация и дизайн (UX)

Собираем таблицу для работы на ПК и наводим «красоту».

Основные параметры вида

  • View: План (Table).
  • Group by: Статья, затем Тип платежа.
  • Group Aggregate: SUM по Week_0…Week_9.
  • Column Order: Контрагент, КЗ, КЗ_Крит, Week_0…Week_9, Статус.
  • Quick Edit Columns: Week_0…Week_9.

Format Rules

  • Жирные заголовки: TRUE → Тип платежа → Bold 1.2.
  • Красный долг: Тип платежа = «Погашение кредиторской задолженности» → Week columns → красный.
  • Черновик: Статус = «Черновик» → Контрагент → иконка карандаш.

Проверка формата цифр

Week... и КЗ должны быть типом Number (не Price), digits = 0.
