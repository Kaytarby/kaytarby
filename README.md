# Шахматка 10 недель — веб-инструкция

Этот репозиторий содержит статичную веб-страницу с пошаговой инструкцией по настройке 10-недельной «шахматки» в Google Sheets + AppSheet.

## Почему «не открывается»

В GitHub файл **сам по себе** не разворачивается как сайт. Нужно либо:

1. **Открыть локально** — двойным кликом по `index.html`.
2. **Включить GitHub Pages** — чтобы страница была доступна по ссылке.

## Запуск локально

Просто откройте файл `index.html` в браузере.

Если хотите через локальный сервер:

```bash
python -m http.server 8000
```

После этого откройте: `http://localhost:8000`.

## Размещение на GitHub Pages

1. Откройте настройки репозитория: **Settings → Pages**.
2. В разделе **Source** выберите:
   - Branch: `main` (или ваш рабочий branch),
   - Folder: `/ (root)`.
3. Сохраните. GitHub покажет ссылку вида:
   `https://<ваш_логин>.github.io/<имя_репозитория>/`.

## Структура

- `index.html` — основной контент с инструкцией.
- `styles.css` — стили.
